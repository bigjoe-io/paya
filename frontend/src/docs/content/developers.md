> [!NOTE]
> The Paya API isn't available yet. This page describes what's planned so you can tell us what you need.

## What's planned

- **Quotes:** live NEAR ⇄ NGN, GHS, KES, TZS and ZAR prices.
- **Payouts:** pay a verified bank account from NEAR, with one API call.
- **Collections:** accept a bank transfer and receive NEAR.
- **Bank checks:** list banks and confirm account-holder names.
- **Webhooks:** signed updates as each order moves.
- **Dashboard:** API keys (test and live), orders, webhook logs and fees.
